# Rachel Frontend

React.js user interface for the **Rachel** Backend.

## Techs

- **TypeScript**: Programming language
- **React.js**: Frontend framework
- **Vite**: Handling build and things
- **MUI**: Design stuff
- **NPM**: Package manager

## Setup

First go inside directory:

```bash
cd frontend
```

Install packages:

```bash
npm install
```

### Run

Just:

```bash
npm run dev
```

- UI: `http://127.0.0.1:5173`
